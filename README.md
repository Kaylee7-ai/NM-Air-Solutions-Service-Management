# NM Air Solutions Service — Service Management Concept

An interactive customer portal and operations-dashboard prototype for NM Air Solutions Service in Tema, Ghana.

## Public listing information used
- Business: NM Air Solutions Service
- Location: Michel Camp Close, Tema, Ghana
- Public phone listing: +233 26 950 4295
- Public listing hours: Monday–Saturday 07:30–18:00; Sunday 12:00–17:00
- Category: air-conditioning repair shop
- Public listing description indicates troubleshooting, repairs and new AC installations, including split-unit installations.

These details must be confirmed by the business before an official launch. This is an independent concept, not an official company website or endorsement.

## Prototype features
- Customer service request form
- Automatic job reference generation
- Job tracking
- Operations dashboard
- Request status management
- Schedule view
- Customer directory
- Quotes and invoices workflow concept
- Operations reporting concept

## Prototype limitations
This GitHub Pages version is a browser-only demo. Requests and status changes are stored in the current browser's local storage; they are not sent to the business, do not sync across devices and should not be used for real customer information. The dashboard is not protected by production authentication. Demo records are fictional.
